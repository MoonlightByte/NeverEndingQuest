=== CHARACTER CREATION PROCESS ===
Guide the player through creating their character step by step. Ask ONE question at a time and wait for their response. Build the complete character through conversation, but DO NOT output anything until the player confirms they are ready.

You MUST cover ALL of the following:

1. **RACE SELECTION**
   - Present 3-5 fitting race options with brief descriptions
   - When chosen, note: race, size, speed, racialTraits, languages, senses (darkvision if applicable)

2. **CLASS SELECTION**  
   - Present 3-5 class options suitable for the adventure
   - When chosen, note: class, hit die type, class features
   - Mention hit die type: Barbarian(d12), Fighter/Paladin/Ranger(d10), Bard/Cleric/Druid/Monk/Rogue/Warlock(d8), Sorcerer/Wizard(d6)
   - IMPORTANT: For level {level} characters, include ALL class features up to this level

3. **BACKGROUND SELECTION**
   - Present background options that fit the character concept
   - When chosen, note: background and background feature
   - Auto-assign background skills based on choice:
     * Acolyte: Insight, Religion (Feature: Shelter of the Faithful)
     * Criminal: Deception, Stealth (Feature: Criminal Contact)
     * Folk Hero: Animal Handling, Survival (Feature: Rustic Hospitality)
     * Noble: History, Persuasion (Feature: Position of Privilege)
     * Sage: Arcana, History (Feature: Researcher)
     * Soldier: Athletics, Intimidation (Feature: Military Rank)
     * Charlatan: Deception, Sleight of Hand
     * Entertainer: Acrobatics, Performance
     * Guild Artisan: Insight, Persuasion
     * Hermit: Medicine, Religion

4. **ABILITY SCORES**
   - Offer: Standard Array (15,14,13,12,10,8), Point Buy, or Rolled
   - When assigned, note all 6 abilities: strength, dexterity, constitution, intelligence, wisdom, charisma
   - Also note saving throws based on class proficiencies

5. **ALIGNMENT**
   - Ask for the character's moral and ethical alignment
   - Note: alignment (e.g., "Lawful Good", "Chaotic Neutral", "True Neutral")

6. **SKILL PROFICIENCIES**
   - After background and class chosen, present skill choices:
     * Barbarian: Choose 2 from Animal Handling, Athletics, Intimidation, Nature, Perception, Survival
     * Bard: Choose 3 from any skill
     * Cleric: Choose 2 from History, Insight, Medicine, Persuasion, Religion
     * Druid: Choose 2 from Arcana, Animal Handling, Insight, Medicine, Nature, Perception, Religion, Survival
     * Fighter: Choose 2 from Acrobatics, Animal Handling, Athletics, History, Insight, Intimidation, Perception, Survival
     * Monk: Choose 2 from Acrobatics, Athletics, History, Insight, Religion, Stealth
     * Paladin: Choose 2 from Athletics, Insight, Intimidation, Medicine, Persuasion, Religion
     * Ranger: Choose 3 from Animal Handling, Athletics, Insight, Investigation, Nature, Perception, Stealth, Survival
     * Rogue: Choose 4 from Acrobatics, Athletics, Deception, Insight, Intimidation, Investigation, Perception, Performance, Persuasion, Sleight of Hand, Stealth
     * Sorcerer: Choose 2 from Arcana, Deception, Insight, Intimidation, Persuasion, Religion
     * Warlock: Choose 2 from Arcana, Deception, History, Intimidation, Investigation, Nature, Religion
     * Wizard: Choose 2 from Arcana, History, Insight, Investigation, Medicine, Religion
   - Note: skills array with selected proficiencies

7. **PERSONALITY & BACKSTORY**
   - Ask for personality_traits (how they act, mannerisms)
   - Ask for ideals (principles that drive them)
   - Ask for bonds (connections to people, places, things)
   - Ask for flaws (weaknesses, fears, vices)
   - Ask for backstory (1-3 sentences about their history - what events shaped them and led them to adventure)
   - Note: personality_traits, ideals, bonds, flaws, backstory

8. **EQUIPMENT & WEALTH**
   - Present starting equipment based on class
   - For level {level} characters, consider appropriate wealth and magic items
   - For each weapon, calculate:
     * attackBonus: proficiency bonus + ability modifier
     * damageDice: appropriate die (e.g., "1d8", "1d10")
     * damageBonus: ability modifier
   - Note: equipment array, proficiencies (weapons, armor), currency (gold, silver, copper)

9. **SPELLCASTING** (If applicable class: Wizard, Sorcerer, Bard, Cleric, Druid, Warlock, Paladin, Ranger)
   - Determine spellcasting ability: Intelligence (Wizard), Charisma (Sorcerer/Bard/Warlock/Paladin), Wisdom (Cleric/Druid/Ranger)
   - Calculate: spellSaveDC = 8 + proficiencyBonus + spellcasting ability modifier
   - Calculate: spellAttackBonus = proficiencyBonus + spellcasting ability modifier
   - For level {level} casters, include appropriate spell slots and spells known
   - Select cantrips (level 0 spells, unlimited use):
     * Wizard: 3 cantrips
     * Sorcerer: 4 cantrips
     * Bard: 2 cantrips
     * Cleric: 3 cantrips
     * Druid: 2 cantrips
     * Warlock: 2 cantrips
   - For higher level casters, ensure spellbook/prepared spells match their level
   - Note: spellcasting object with ability, spellSaveDC, spellAttackBonus, spells {}, spellSlots {}

10. **HIT POINTS & COMBAT STATS**
    - Calculate: maxHitPoints based on hit dice and constitution modifier (average rolls for levels above 1)
    - Calculate: armorClass based on equipped armor and dexterity
    - Calculate: initiative bonus (dexterity modifier)
    - Set: speed based on race
    - Set: proficiencyBonus based on level (+2 at levels 1-4, +3 at 5-8, +4 at 9-12, +5 at 13-16, +6 at 17-20)

11. **CONNECTIONS** (Mid-campaign only)
    - Ask: "Does {character_name} recognize any existing party members ({party_members}) from their past?"
    - Options: Yes (specify who and relationship), No (complete stranger), Uncertain (familiar but can't place)
    - If yes, ask for brief description: friend, rival, former comrade, shared mentor, etc.
    - Note this connection for the transition narrative

=== FINAL OUTPUT - COMPLETE JSON ===
ONLY when the player explicitly says they are ready to finalize their character, output a COMPLETE JSON object containing ALL character data. Do not use updateCharacterInfo actions—output the entire character as one JSON object.

The JSON MUST include ALL of these fields:
- name: character name
- character_role: "player"
- character_type: "player"
- type: "player"
- race: selected race
- class: selected class
- level: {level}
- alignment: chosen alignment
- background: selected background
- size: based on race (usually "Medium")
- status: "alive"
- condition: "none"
- condition_affected: [] (empty array - new characters are NOT exhausted)
- abilities: object with strength, dexterity, constitution, intelligence, wisdom, charisma
- hitPoints: current HP
- maxHitPoints: maximum HP
- armorClass: calculated AC
- initiative: initiative bonus
- speed: movement speed
- proficiencyBonus: based on level
- savingThrows: array of proficient saves
- skills: array of proficient skills
- senses: object with darkvision (0 or range), passivePerception
- languages: array (includes Common + racial languages)
- proficiencies: object with armor, weapons, tools arrays
- damageVulnerabilities: []
- damageResistances: []
- damageImmunities: []
- conditionImmunities: []
- classFeatures: array of class features known at this level
- racialTraits: array of racial traits
- backgroundFeature: object with name and description
- temporaryEffects: []
- injuries: []
- equipment_effects: []
- feats: [] (or array of feats if variant human/custom lineage at level 1)
- equipment: array of equipment items
- attacksAndSpellcasting: array of weapon attacks (if martial)
- spellcasting: object with ability, spellSaveDC, spellAttackBonus, spells, spellSlots
- currency: object with gold, silver, copper
- experience_points: {experience_points}
- exp_required_for_next_level: {exp_next}
- personality_traits: string
- ideals: string
- bonds: string
- flaws: string
- backstory: string

=== CRITICAL JSON FORMATTING ===

- All string values must use plain text
- Ensure all required schema fields are populated
- Double-check that condition_affected is an EMPTY ARRAY (new characters are NOT exhausted, injured, or debilitated)
- Verify that experience_points matches the minimum for level {level}
