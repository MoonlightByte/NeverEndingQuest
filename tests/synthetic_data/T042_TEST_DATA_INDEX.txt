Location: core/managers/combat_manager.py:1801

Function: generate_combat_round_summary(round_num, round_messages)

Input:
  - round_num: int (current combat round number)
  - round_messages: list of {role, content} dicts

Output:
  - JSON dict with: round, actions, deaths, status_changes,
                    resource_usage, narrative_highlights, round_end_state

Purpose:
  - Compress raw combat turn exchanges into structured data
  - Extract mechanical facts (actions, rolls, damage, HP changes)
  - Extract narrative moments (dramatic highlights)
  - Track resource consumption (spell slots, hit dice, abilities)
  - Track creature status (HP, conditions, alive/dead state)

Model: DM_MINI_MODEL (see model_config.py)
Temperature: 0.1
Response Format: JSON object
