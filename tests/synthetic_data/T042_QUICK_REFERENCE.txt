================================================================================
COMMON VALIDATION POINTS
================================================================================

Action Count Accuracy:
- Example 1: Expect 1 action (Snow Rat flee)
- Example 2: Expect 3 actions (Fireball, Shortbow, Wolf Bite)
- Example 3: Expect 3 actions (Cure Wounds, Charm Person, Scimitar)
- Never more, never fewer, never invented

Damage Math Verification:
- Example 2: Kira heals 14 from 28-damage Fireball (save for half = correct)
- Example 3: Lyssa heals 16, then takes 10, should show 11/32 HP (math correct)

HP Tracking:
- Check round_end_state shows correct current/max format
- Verify all HP changes from "current HP" → actual new value match actions
- Example 2: Ranger Thane 33→25 (took 8 damage)
- Example 3: Lyssa 5→21→11 (healed 16, took 10)

Condition Application:
- Example 3: Must show "poisoned" and "charmed" in Lyssa's conditions
- Must appear in both status_changes AND round_end_state.conditions

Spell Slot Tracking:
- Example 2: Malarok used 3rd level slot (Fireball)
- Example 3: Both characters used appropriate slot levels

Death Handling:
- Example 1 & 2: deaths should be empty []
- Example 3: deaths should be empty [] (pre-round deaths, not THIS round)
