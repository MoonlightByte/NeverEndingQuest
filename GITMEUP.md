# Contributing through GitMeUp

Project: https://gitmeup.com/projects/neverendingquest-381865

Current opportunities: https://gitmeup.com/projects/neverendingquest-381865#help

GitMeUp connects people with this project and provides a portable handoff.
An offer expresses interest; it does not reserve an issue or guarantee a merge.
Repository rules, licensing, code review and merging remain here on GitHub.

## Before starting

1. Choose a focused opportunity and discuss unclear scope with the maintainer.
2. Read the current [README contribution guide](README.md#contributing),
   [CLAUDE.md](CLAUDE.md), [architecture philosophy](ARCHITECTURE_PHILOSOPHY.md),
   [architecture reference](ARCHITECTURE.md) and [licensing terms](LICENSING.md).
3. Check for additional instructions in the directories you will change.
4. Copy or download the opportunity handoff from GitMeUp. Imported repository
   files are dated snapshots; check the current versions here before working.
   If the portal brief conflicts with repository guidance, ask the maintainer.

## Working with an AI assistant

Give your assistant the selected opportunity, its handoff and applicable
repository instructions. Keep changes focused, review generated work, and run
the checks relevant to the affected area. A copied brief does not confirm an
assistant read or followed it. Do not post API keys, provider captures, private
campaign data or other secrets in the portal, issues or pull requests.

## Delivering and handing off

Include the environment, steps and expected versus actual results for a test
report. For code, follow repository contribution requirements and include the
relevant test commands and results. Record work completed, remaining work,
blockers and assumptions; link your branch or pull request when applicable.
A concise test report or documentation improvement can be useful without a PR.

Update your offer in GitMeUp so the maintainer can respond. Use your own GitHub
account for a linked PR. You may include this optional attribution in your PR
description or report:

Found this opportunity through GitMeUp: https://gitmeup.com/projects/neverendingquest-381865

The attribution is a contributor statement, not independent proof of origin.
