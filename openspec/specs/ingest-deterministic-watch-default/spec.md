## Requirements
### Requirement: Watch-folder markdown ingest MUST use deterministic parser path
The ingest watcher MUST invoke importer with deterministic mode enabled for watched `.md`, `.markdown`, and `.txt` sources.

#### Scenario: New markdown source appears in watch folder
- **WHEN** watcher processes a supported markdown/text file from `modules/ingest/`
- **THEN** importer is invoked with deterministic mode enabled
- **AND** canonical IDs are generated by deterministic parser rules

#### Scenario: Deterministic ingest fails validation
- **WHEN** deterministic ingest output fails strict validation
- **THEN** watcher archives source as `quarantined`
- **AND** no registry registration is performed

### Requirement: Watcher startup MUST remain fail-open
Watcher initialization errors MUST NOT block web server startup.

#### Scenario: Watcher import or start raises exception
- **WHEN** startup hook attempts to initialize watcher and an exception occurs
- **THEN** server startup continues
- **AND** warning log captures watcher startup failure
