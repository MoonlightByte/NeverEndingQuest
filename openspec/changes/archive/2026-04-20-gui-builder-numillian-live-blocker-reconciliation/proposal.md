## Why

The Numillian canary no longer fails for broad pipeline reasons. It now fails because the live module, validator, and deterministic repair paths disagree about four exact blocker classes: monster authority, monster schema canonical recovery, conclusion-edge prerequisite targeting, and area/map spatial parity. This change is needed now so the canary can advance beyond the current five-failure floor before any Phase 2 LLM classification work begins.

## What Changes

- Add deterministic reconciliation for validator-visible monster references that are currently filtered out of module monster authority because the same identity is also cataloged as an NPC.
- Add authoritative canonical recovery for monster schema completion when the compendium/source identity differs from the on-disk monster slug by safe variants such as singular/plural forms.
- Modify plot prerequisite repair to target the validator-failing conclusion edge rather than the numerically terminal plot node.
- Add deterministic area/map parity reconciliation for spatial coordinates so repaired area layouts also update the paired `map_*.json` files before residual debt classification.
- Extend blocker-resolution reporting to show whether the Numillian canary advanced after live blocker reconciliation and which residual failures remain true author/content debt.

## Capabilities

### New Capabilities
- `toolkit-numillian-live-blocker-reconciliation`: Reconcile the exact live Numillian validator/repair mismatches that still survive residual convergence closure.

### Modified Capabilities
- `homebrew-ingest-monster-materialization`: Monster closure and schema completion requirements must cover authoritative canonical recovery and validator-targeted reconciliation.
- `tt-monster-reference-integrity-validation`: Validator-visible monster references must remain reconcilable with authorized repair paths when authored module content uses the same identity across surfaces.
- `module-plot-progression-path-validation`: Deterministic repair/support paths must target the validator-failing conclusion dependency edge, not just the terminal plot node.
- `tt-spatial-coordinate-resolution`: Spatial remediation requirements must include paired area/map parity reconciliation before structural-debt escalation.
- `module-publishability-reporting`: Canary/reporting artifacts must distinguish reconciliation advancement from unchanged residual author/content debt.
