# ADR Directory

This folder stores durable architecture decisions for the tabletop NeverEndingQuest build.

Use `index.md` as the canonical list.

Authoring rules:
- Keep each ADR focused on one durable decision.
- Prefer updates to existing ADRs over duplicate new ADRs.
- Record cross-links with `Supersedes` and `Superseded by` fields.
- Reference local project evidence (`AGENTS.md`, `openspec`, `plans`, and legacy `memory-bank` when relevant).

Update workflow note:
- AGENTS remains canonical governance for repo-wide policy.
- ADRs capture stable "why" decisions that outlive individual OpenSpec changes.
