# ADR-0028: Homebrew Wave 1 Birble Plan Deferred After Dev Ingest Validation

- Date: 2026-03-10
- Status: Deferred
- Supersedes: None
- Superseded by: ADR-0023

## Context
Original Wave 1 planning prioritized Birble ingest as a first target. The dev ingest pipeline and continuity gates were later validated on active modules, changing immediate priorities.

## Decision
Archive the Birble Wave 1 plan as deferred and proceed with current validated dev-ingest workflow. Revisit Birble during full homebrew ingest rollout.

## Consequences
- Reduces near-term scope pressure.
- Preserves historical planning context without blocking current delivery.
- Birble ingest remains an explicit future backlog item.
